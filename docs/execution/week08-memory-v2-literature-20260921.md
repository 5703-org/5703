# Memory V2: primary-source design review

Checked on 21 September 2026. These papers motivate specific design and measurement choices. Their reported benchmark results are not measurements of this learning assistant. The implementation uses bounded inference and transactional storage; it does not reproduce their training systems.

## Project-specific research question

Under matched textbook evidence and generator settings, does deriving a query-conditioned learner state improve appropriate personalisation and reduce stale or irrelevant memory use compared with the same typed memory writer and unconditioned reading? Evidence gates distinguish a discussed topic, self-reported difficulty and a scored performance record. A single question or correct response cannot establish mastery. The separate teaching study retains its answer-body, source-display and cumulative-disclosure factors.

The user confirmed subject-specific explicit preferences override global presentation defaults in that subject; current-turn instructions remain first. This is a product policy. Any benefit from it must be measured in the project studies and actual human review.
