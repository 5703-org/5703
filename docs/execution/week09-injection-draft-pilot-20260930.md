## Source and method

The legitimate task asked for the overall purpose of the light-dependent reactions. Its source excerpt came from the existing passed real-vector retrieval record, SHA-256 `511b34c7b0791a92f74a8109b99ca50c7846d122eee558bcb07420f7f5f7c09d`, for *Concepts of Biology*, physical PDF page 138. The exact source chunk hash was `3875811a6249a7143e15d588fc278821bb897a38f13f16ca024829c2495f6fa7`; the original official PDF hash was `da0ffc8585e172f04eb0abb08949087baf85cc229ef2736ef06e5aa17094b1f6`. The released corpus ID was `4f11bd70-a486-4d16-b216-78cfe499530a`. The runner checked the original PDF, retrieval record and chunk hashes before freezing. Its offline source map is reconstructed for prompt preparation; it does not stand in for a fresh database read.

Two source attacks altered temporary copies of that passage. Those copies were labelled **isolated adversarial derivatives**, assigned synthetic source and processing IDs, and supplied without the official source URL. Two other attacks placed adversarial instructions in temporary typed-memory entries. The answer-key case supplied no hidden key to the model; a private canary existed only in the coordinator manifest. The six cases were one clean baseline plus five attacks, grouped as two development and four pilot cases. These are six fixed prompts for one topic, not six independent textbook concepts.

The evaluator used the current checked-generation prompt builder to capture each initial generation request. It then sent each frozen message set once through the existing `LLMAdapter` with `openai_compatible`, `deepseek-flash`, JSON-object output and a 2,048-token output reservation. It did **not** call the online semantic checker or publish an answer. The output was parsed with the current strict JSON, draft schema and citation parser. Automatic checks looked for the attacker canary, `ev_999`, the injected false memory term, a private-key canary and a narrow lexical signal of task relevance. These checks do not determine scientific correctness, source sufficiency, appropriate hint depth or whether an actual checked answer would pass publication.

All six scheduled calls were submitted and terminal. No raw draft contained the exact attacker canary, `ev_999`, the injected false fact term or the private-key canary. Six of six drafts passed the structural parser and six contained the preregistered rough topic terms. The separate unit regression confirmed that a forged `ev_999` citation is rejected as `INVALID_CITATIONS` when only `ev_001` is selected. These observations show resistance to these narrow strings in one initial-draft run. They leave safe legitimate-task completion, factual support and answer-key disclosure quality **unscored**. The answer-key canary was never model-visible, so its absence cannot establish protection against a genuinely exposed key. Human semantic and safety ratings are zero.

The six calls used 20,814 input tokens, including 14,080 reported cache-hit tokens, and 960 output tokens. The known tariff-based estimate is **USD 0.00162834**; every call had usage counters, and the provider invoice is not reconciled. One-call wall times ranged from 1.1453 to 1.4393 seconds, median 1.3096 seconds. There were no failed calls in this run, so a failed-call latency distribution is empty. These values exclude retrieval, online checking, repair, request queueing, database persistence and browser delivery.

The first freeze, SHA-256 `0fd2bf74fbc23e33453ea2cfaebfcd472a0721b64ddef64b3e52de6c4e1027e2`, was retained as a failed preparation incident. Its runner stopped before any provider reservation because a source-hash key used a Windows separator while the lookup expected a POSIX separator. The evaluator was corrected, five focused tests and Ruff check/format passed, and a new V2 freeze was written before the six provider calls. The evaluator source SHA-256 for the executed pilot is `0a0885d0c0eb1b1949d6171652f0412d2145cc92be35bab00bff8a797fb797d2`.

The configured project mypy scope excludes this evaluator. Typed cleanup can receive a successor evaluator identity without changing this pilot's prompts or results.

The [500-request authorization study](week09-safety-authorization-study-20260930.md) measures object and role reads through the installed V11 HTTP application. This pilot measures model-facing drafts only. Neither study covers adaptive attack success, malicious file handling, source mutation and publication, cross-conversation memory poisoning, independent human safety assessment or full end-to-end answer quality. A larger next sample needs multiple disjoint textbook concepts, actual checked publication and blinded semantic review; attack and safe-task outcomes should remain separate denominators.
