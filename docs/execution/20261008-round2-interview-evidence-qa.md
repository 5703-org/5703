# Interview evidence: quote repair and failure diagnostics

The project now has a concrete diagnosis for its slowest measured checked answer. The 32.933-second dense diffusion answer spent 23.068 seconds repairing a checker-produced source quote containing a new ellipsis. The validator correctly rejected that quote; weakening source validation would defeat the reliability design. The local prompt now explicitly requires contiguous verbatim quotation while preserving the full original prompt and every scientific/citation/proof gate. Sixty-four existing offline product-gate tests pass. Live latency after this repair remains unverified.

The new retrieval diagnostic uses twelve previously seen failure cases and one frozen public corpus/model/policy. Dense top five contains twelve exploratory rule-positive chunks out of sixty; RRF and MiniLM top five each contain nineteen. Recall is explicitly candidate-pool recall: twelve or nineteen selected positives divided by thirty-five finite-pool positives. Labels are lexical rules, not human relevance or complete evidence sufficiency. MiniLM worsens two questions against the same RRF candidate set, so an aggregate score alone hides regressions.

A full scoped scan of 10,594 public chunks separates retrieval pool limitations from corpus lexical coverage. The buoyancy question has twenty-two rule-positive corpus chunks, only one in the frozen candidate pool, and none in the selected top five. Four questions have zero relationship-rule matches in the corpus, but this cannot establish scientific absence because a rule can miss paraphrases. The native automatic estimator is a separate word-coverage signal and never certifies semantic sufficiency.

The prospective noRAG/dense/hybrid OpenQA test keeps model, knowledge permission, JSON shape, history/profile policy and original scoring identical. Twelve times three inputs are frozen, with previously successful questions excluded. Whole-answer synonym classes were fixed before new generation; original EM/token-F1 remain the primary scores. No new model answers or scores exist yet.
