# Fixed-ID checker implementation and bounded comparison

The isolated implementation improved observed contract compliance, but failed the admission test: one response was invalid JSON and independent review found three false support certifications plus one false insufficiency. It remains outside the default application path. The declared error-stop rule closed the experiment after six requests; there is no retry or further experiment in this direction.

The new module is `generation/experimental_fixed_id_checker_v1.py` (17,908 bytes; SHA256 `cfa5948069edcbddcc504a59fac7cf178c58bb743ac13d2b691974e9397e991f`). Program code freezes assertions, requirements, source identities, fixed IDs and each parent's allowable references. The model returns only ID, status and selected references. At most eight targets are batched; every batch retains the complete submitted source table and permits joint evidence. Strict parsing, legal mapping and complete coverage are separate from scientific entailment. The module cannot authorize answer publication, infer missing provenance, populate the original parent fields or replace the production validators. Its saved-input compiler currently depends on the pinned local B codec; this is an experimental implementation, not a portable application integration.
