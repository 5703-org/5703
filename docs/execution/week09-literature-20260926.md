# Research basis for Week 9

The Week 9 method combines progress-aware hint planning with source-display planning, after shared repairs to the generation and checking contracts. The four factorial arms hold corpus, models, budgets and publication checks fixed. Memory selection has its own paired comparison. The [registered protocol](week09-generation-protocol-20260926.md) defines the local experimental design.

| Primary source | Relevant finding or method | Project use |
| --- | --- | --- |
| [RAGChecker, NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/hash/27245589131d17368cccdfa990cbf16e-Abstract.html) | Diagnoses retrieval and generation separately using fine-grained measurements. | Separate missing context, unused context, draft defects and checker decisions in the failure catalogue. |
| [Sufficient Context, ICLR 2025](https://arxiv.org/abs/2411.06037) | Examines whether the supplied context contains enough information to answer. | Record context sufficiency independently of whether a draft is supported; reserve semantic sufficiency for labelled review. |
| [RefChecker, EMNLP 2024](https://aclanthology.org/2024.emnlp-main.395/) | Extracts fine-grained claim triplets and checks them against references. | Independently classify explicit draft assertions and assess their actual cited source bindings. |
| [ALCE, EMNLP 2023](https://aclanthology.org/2023.emnlp-main.398/) | Evaluates answers and citation quality as distinct dimensions. | Keep answer correctness, citation support and completeness separate in automatic records and human forms. |
| [RARR, ACL 2023](https://aclanthology.org/2023.acl-long.910/) | Finds supporting information and revises unsupported generated content while preserving the original response where possible. | Target defective bindings and assertions; recheck the complete final visible response after repairs. |
| [JSONSchemaBench](https://arxiv.org/abs/2501.10868) | Examines structured-output efficiency, constraint coverage and output quality with a diverse schema benchmark. | Probe the application's actual draft and checker schemas; retain distinct connectivity and contract results. |
| [DeepSeek JSON mode](https://api-docs.deepseek.com/guides/json_mode/) | Documents JSON-mode instructions and the possibility of empty content. | Compare supported output modes and legal examples on development inputs; record actual empty output and counted recovery. |
| [MathDial, EMNLP Findings 2023](https://aclanthology.org/2023.findings-emnlp.372/) | Organizes tutoring around pedagogical dialogue actions grounded in reasoning tasks. | Represent a current-step action and expected learner response before generating a hint. |
| [BEA 2025 pedagogical ability assessment](https://aclanthology.org/2025.bea-1.77/) | Separates dimensions of tutor feedback such as error identification and actionable guidance. | Judge learner-attempt feedback, usefulness, current-step scope and cumulative disclosure separately. |
| [LongMemEval, ICLR 2025](https://proceedings.iclr.cc/paper_files/paper/2025/hash/d813d324dbf0598bbdc9c8e79740ed01-Abstract-Conference.html) | Evaluates long-term conversational memory across retrieval, reading and changing information. | Measure selection errors and omissions, preserve source conditions and updates, then examine actual preference application. |
| [RouteLLM official implementation](https://github.com/lm-sys/RouteLLM) | Provides training and evaluation of routers that choose between model configurations using preference-based data. | Retain routing as a later data-dependent comparison; measure present role configurations and avoid assuming a different model improves quality. |
| [AlignScore paper](https://aclanthology.org/2023.acl-long.634/) and [official implementation](https://github.com/yuh-zha/AlignScore) | Scores factual consistency using a trained text-alignment model and document/sentence aggregation. | Evaluate compatibility and actual CPU contrast behavior in an isolated environment before considering an online precheck. |

The local four-arm method is a project design informed by these sources. Its supported-hint delivery, repair count, latency and cost are measured on the project's own frozen inputs. Independent reviewers assess exact accepted and rejected drafts. Labels from the online checker remain automatic observations. Learning gain and delayed transfer require separate learner studies.
