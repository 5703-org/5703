Follow-up research suggestions (not proven cures): the [official provider-routing guide](https://openrouter.ai/docs/guides/routing/provider-selection) distinguishes a fixed provider from supported-parameter routing; the existing Luna wire retained require_parameters=true. ALCE/RefChecker/MiniCheck-style claim/condition IDs plus exact supplied-source spans are candidates for free replay of saved erroneous judgments before any schema or workflow change. Derive aggregate coverage from verified memberships, retain unsupported/contradicted/insufficient distinctions, and check over-blocking; do not invent gold labels or accept invalid whole responses. The [DeepSeek chat API contract](https://api-docs.deepseek.com/api/create-chat-completion/) lists text/json_object; strict tools on its separate beta path and thinking/tool-choice restrictions cannot be assumed equivalent to OpenAI json_schema. Only existing actual wires may establish what this project sent; no new paid route test is authorized here.


Primary papers checked in this phase: [RefChecker](https://arxiv.org/abs/2405.14486) checks extracted fine-grained claims against references; [ALCE](https://aclanthology.org/2023.emnlp-main.398/) evaluates factual correctness and citation quality separately; [MiniCheck](https://aclanthology.org/2024.emnlp-main.499/) studies document-grounded fact checking; [RARR](https://aclanthology.org/2023.acl-long.910/) studies researching and revising generated claims while retaining content. These are method precedents, not proof of a reliable checker or an up-to-date industry ranking. Project adaptation is an inference: replay paired known false blocks and true errors; verify existing IDs and exact-span membership; derive aggregate coverage; separately adjudicate entailment, contradiction and insufficient evidence. A span existing is not proof it entails a claim. Compare 0/1/2 bounded repair rounds on net corrections, regressions, time and cost; two is not presumed optimal. Start with one-factor small calibration, then freeze the formal design; avoid a Cartesian experiment. No new schema, model route or research behavior was implemented here.
