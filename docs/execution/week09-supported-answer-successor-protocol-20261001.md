# Supported-answer successor: frozen development protocol

## Baseline and purpose

This increment addresses concrete normal-product failures in the four-case real
DeepSeek development execution recorded on 1 October 2026. Both the typed V5 and
compact V7 arms delivered two of four requests. Delivery is an engineering
endpoint; independent correctness, evidence sufficiency and checker calibration
remain unscored.

Before edits, all 798 Gate04 source inputs were rehashed and copied to an
exclusive private baseline. The baseline receipt SHA256 is
`9f07c3c1a8d536de4a9d490fe1d01e60edfde2235137b308089301f27ababd6e`.

The preceding software gate certifies that retained baseline, not this increment.
Every original draft, failed check, attempt and published answer is retained.

## Candidate boundaries

The prospective `scoped_compact_v8` policy is opt-in. The default checker remains
`typed_joint_v5`. The V5, V6 and V7 prompt and validation paths retain their
recorded behavior. V8 retains the strict compact V6 response schema, factual-unit
judgments, actual-citation assessments, independent requirement judgments and all
final factual, source, teaching and disclosure gates. Its added claim-local
reference view is source identity metadata, with no entailment certification.
It must not attach an uncited source, replace an actual citation with an
alternative, turn a negative judgment into support, or increase request budgets.

The prospective V17 query policy preserves V16 preparation and introduces a
separately versioned requirements grammar. Pure presentation instructions are
retained as presentation requirements rather than invented textbook knowledge
gaps. Actual scientific objects, actions, relations, conditions, negations,
numbers and units remain knowledge requirements. Historical V16 requests keep
their original dispatch. Query preparation is evaluated separately from the
fixed-material generation/checking comparison.

Every request retains four provider calls and 180 active seconds, including
format recovery, checking, repairs and final verification. Honest evidence gaps
remain visible. A useful supported partial response requires exact named gaps
and all existing release checks; the software never supplies a positive model
judgment to manufacture completeness.

## Evaluation and release evidence

Report delivery, first-check acceptance, contract corrections, content repairs,
fresh final-check acceptance and calls per policy and paired question. Record
draft revisions, actual citation scopes, requirement coverage, selected/submitted/
cited counts and every rejection code. Show all, successful and failed timing
populations separately; four questions do not establish production p95 latency.

The original sequence made 25 calls, consuming 308,148 input and 28,059 output
tokens. Its conditional historical tariff estimate is USD 0.038446272, not an
invoice or Week 9 total. Successor usage and cost require their own dated records;
missing or uncertain usage is unpriced. Human ratings remain zero until actual
independent group scoring is imported.

Regression tests must cover missing local citations, another claim's source,
irrelevant/contradictory citations, omitted independent gates, honest partial
support, lost conditions and unchanged legacy dispatch. New source requires a
new full software gate and installed runtime evidence before an updated archive
is selected. The current verified delivery is retained throughout development.

## Research basis

[RefChecker](https://aclanthology.org/2024.emnlp-main.395/) separates fine-grained
claims from their reference-based checks. This project uses that distinction to
inspect source identity separately from semantic support; no published benchmark
score is transferred to this system. The
[DeepSeek JSON guidance](https://api-docs.deepseek.com/guides/json_mode/) requires
JSON prompting and recommends an output example and sufficient output allowance.
The added legal examples guide the existing schema rather than certify the
generated content or bypass its checks.

are in progress; no successor provider call or independent rating has occurred.
