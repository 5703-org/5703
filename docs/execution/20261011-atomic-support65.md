The complete eight-case batch returned without truncation or coordinate errors.
All eight short judgments pass the unchanged strict atomic contract after unique
literal quotes are located inside their own actually cited fragments. The compact
contract is useful as an explicitly called local evaluation component. Semantic
and selected-witness failures remain, so default semantic integration is blocked.

## Change and free verification

Added `generation/atomic_support_compact_v1.py`, its matching prompt, and
`tests/unit/test_atomic_support_compact_v1.py`. The model returns short quotes,
verdicts, reasons and gaps; local code derives Unicode codepoint coordinates and
calls the existing strict validator. It never searches an uncited source or a
sibling fragment, resolves repeated quotes by guessing, or rewrites semantics.
The default checked workflow, existing core and route settings remain unchanged.

Main normal-import verification passed **37 tests** (9 compact, 19 strict atomic,
9 quote binding) and touched-file Ruff. Eight free replays of the retained actual
replies through the promoted Main module exactly match their original saved
bindings. Those checks use isolated in-memory fixtures and make no provider or
database calls. The original response qualification and old ledgers are preserved.

## Fixed protocol and separate denominators

The inputs are AI-authored synthetic development fixtures: two explicit-support
positive controls, two explicit counterexamples, two missing-value cases, and two
missing-identity cases, across cart velocity and record completion domains.
An independent AI reviewer froze condition expectations before seeing outputs.
These are neither human Gold nor held-out data. Positive controls explicitly state
the outcome, so they do not prove independent numerical derivation ability.

All eight first attempts used the same `google/gemini-3.5-flash-lite` model,
Vertex-only `google-vertex/global` route, high reasoning, strict JSON schema,
4096 total-output token cap and 60-second adapter timeout. Four optional 8192-token
repairs were reserved exclusively for settled truncation, in fixed case order
after all bases. None was triggered. Opinions, schema or binding failures could
not trigger a retry. The eight-case batch is closed; four conditional slots expired.

Before transport, 16 exact base/repair wires passed byte, conservative input/output
budget and route checks; only `max_tokens` differs in each pair. Twenty free
controller policy/accounting tests passed. Independent review found and resolved
an abnormal-metadata accounting path: observed finite cost is now durably reserved
before metadata interpretation, financial settlement and output validation.
