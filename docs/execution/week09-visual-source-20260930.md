# Week 9 source-bound visual-region extraction

This additive extraction uses the four acquired, hash-pinned official OpenStax PDFs and leaves the active 10,594-vector E5 corpus, stored answers and citations unchanged. The extractor is `pymupdf_visual_regions_v2` on PyMuPDF 1.28.2. It records physical PDF page, page-visible rectangle, original image rectangle where clipping occurs, native caption or symbol text, source hash, content-derived region ID, and explicit review status. It reconstructs candidate table cells when PyMuPDF recognizes a table. A formula pattern identifies a candidate line; it does not certify notation or mathematical meaning. Image semantics are not inferred.

The full source scan is [visual-full-attempt2/manifest.json](../../evidence/week09-continuation/20260930/visual-full-attempt2/manifest.json). Each compressed JSONL catalog and the source PDF is SHA-256 verified before import. The [120-region review manifest](../../evidence/week09-continuation/20260930/visual-review-v2/manifest.json) audits every catalog identity and rectangle, then selects ten distinct physical pages per book and candidate type. Its [review sheet](../../evidence/week09-continuation/20260930/visual-review-v2/review-sheet.csv) has empty reviewer and judgment columns; these are not human ratings or scientific validation.

The first complete extractor pass, [visual-full-attempt1](../../evidence/week09-continuation/20260930/visual-full-attempt1/manifest.json), recorded raw PDF image rectangles. The subsequent geometry audit caught 131 images partly outside the visible page, including trim/bleed artwork. The revision clips the *visible locator* to the physical page and preserves the unmodified raw rectangle in `details.raw_bbox_points`. Both passes and the failed audit attempt remain available. No candidate is silently excluded to obtain a zero-error result.

`scripts/verify/build_visual_region_catalog.py` rebuilds a new immutable catalog directory from originals; `scripts/verify/prepare_visual_review.py` validates and samples it; `scripts/verify/import_visual_regions.py` verifies original hashes and candidate identity before an optional database import. The additive `visual_regions` table stores candidates separately from released chunks and vectors. `visual_region_reviews` stores a later administrator decision separately; even an accepted geometry/text review does not make a visual candidate eligible as answer evidence. The admin API lists candidates and their status and serves a pinned original page for inspection. The learner page-view route checks the released document version and source hash before rendering the stored PDF. Future caption/transcription use requires a separate source-specific semantic review and corpus release procedure.

The [main migrated PostgreSQL import](../../evidence/week09-continuation/20260930/main-visual-candidates-import.json) installed all 5,543 candidates; a second import added zero. All review fields remain unfilled and no candidate is published as answer evidence. The [isolated browser checkpoint](../../evidence/week09-learning/20260930/frontend/ui-checkpoint-final.json) includes administrator candidate/page inspection. After installing the official corpus, startup verifies and idempotently imports all 5,543 visual candidates before launching services. It resolves each original PDF from installed or bundled storage by exact SHA-256; a missing or mismatched source, catalog or import stops startup. The four exact derived catalog paths/hashes retain OpenStax CC BY-NC-SA provenance and needs-review states. Import does not add them to released answer evidence or establish scientific correctness.

Remaining validation: independent review of the 120 source regions, text/table reading order, image labels and visual relationships, formula symbols and units, downstream question-answer effects, and the complete fresh-install/recovery execution. The deterministic scan and audit establish source traceability and identify work; they do not establish full-book visual fidelity.
