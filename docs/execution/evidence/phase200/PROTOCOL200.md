# Phase200 fixed new-question experiment protocol

The accepted source is an isolated Candidate200 derived from the verified Main198 baseline and the integrated Candidate199 delta. Main source integration does not demonstrate that any previously loaded Main service has been restarted. Existing configuration, databases, keys, old archives, protected UNKNOWN charges and the stopped 48-unit pilot are outside this experiment.

## Frozen design

Five question-only inputs are frozen in `QSET200.json` (SHA256: d130f6264bf7fa2518b627090e2e4db56f74d005a22d435d4889b9a48ff01643). They cover definition, comparison, multipart explanation, units/calculation, and explicit general knowledge without retrieval. The independent reviewer rubric is not an application input and is never copied into a model request, task label, corpus or runtime fixture. Questions have no exact overlap with the previous six-question set. This is a fresh held-out operational set, not a claim of model-training blindness.

Run one fresh-worker OFF cohort N1 through N5, close and preserve it, then run one fresh-worker ON cohort N1 through N5 using identical frozen product source. Each cell has a fresh session, no history, no profile and direct teaching mode. The real browser selects the requested answer mode and Checker checkbox. Preserve native task classification and assertion-policy admission/fallback. The normal full retrieval cache remains enabled; the index-only variant remains disabled. Public CPU model and release preparation completes before per-request measurement; no question is prefetched.

There is no randomization, repeat, repair, output-based question replacement or extra evaluator model. Cohort order and the five-item sample limit causal or population latency conclusions. The previous 5.381-second answer is historical evidence only and is not rerun to improve its score.

## Physical submissions and failure handling

OFF reserves five GEN slots and no CHECK slots (CNY2.50). ON reserves five GEN and five CHECK slots (CNY5.00). Every physical stage has a nontransferable CNY0.50 hold. Maximum scope is ten GEN plus five CHECK submissions and CNY7.50 holds under a CNY8.00 ceiling. No retries, probes or remote token counting are permitted. All provider execution uses the existing reviewed `phase192/runtime/launch192.py` entrypoint through official approval. Unused slots do not authorize any alternative call.

A failed cell can advance only after the native owned job is durably `failed`, its request is `error`, its execution token is cleared, no answer exists, all admitted stages are a legal planned prefix with KNOWN usage, the exact finite functional error is permitted, and no uncertainty, transport, ownership or policy STOP exists. It remains a failure in the denominator. An unused CHECK stays NOT_RUN. Any unknown charge, transport uncertainty, policy/ownership break, unclassified exception or observer error stops the cohort; stop state is never cleared. The ON cohort requires complete OFF lifecycle closure and zero protected UNKNOWN holds.

## Endpoints and independent assessment

For all five cells in each mode, report native durable publication and successful complete answer rendered latency. A failed/unrun cell has NULL complete-answer latency, with separate observed failure/censor time; it never becomes a successful timing sample. The primary target is a scientifically correct and complete OFF answer rendered within ten seconds. Report its numerator over all five OFF cells. Show individual timings and stage durations rather than production p95 claims.

Keep four dimensions separate: delivery, scientific correctness/completeness against the frozen independent rubric, citation support against the actual submitted evidence and public bindings, and native Checker status. A native Checker pass is not independent scientific truth. General knowledge must show no retrieval/reranking invocation and no textbook evidence/citations, with its native unverified provenance. Citation support is not applicable to that explicitly unsupported mode. Q6 from the earlier set remains PENDING_SCIENTIFIC_REVIEW and its flag files stay byte-identical.

Record actual complete request/token/schema evidence, stage durations, physical count, usage-known status and conservative usage-based CNY cost. Costs are not a provider invoice. Native counterfactual codec savings are local estimates only; do not present them as a randomized provider latency comparison. Preserve every required assertion, source fragment, evidence identity and CHECK output schema, with the same 4096-token CHECK reserve. Select the reversible lossless codec only when the full native wire request is smaller; fall back to the old encoding otherwise.
