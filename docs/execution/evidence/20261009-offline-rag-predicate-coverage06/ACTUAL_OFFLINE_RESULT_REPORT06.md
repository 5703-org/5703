## Evidence and limits

`ACTUAL_OFFLINE_RANKING_COVERAGE06.json` contains complete rankings/scores, all ten stage selections, actual fragment IDs, coverage and missing-fragment sets, counts, source/definition pins and operation counters. `OFFLINE_BIOLOGY_WIRE_POOL_INPUT06.json` preserves the exact reconstructed wire-item inputs and all unchanged separate fragments. `ACTUAL_FREE_OFFLINE_CONTROLS06.json` records28 passing controls. The executable is `runner/run_offline_rag_coverage06.py`; it AST-extracts only the actual Main tokenizer/BM25/index definitions and blocks socket/process operations. It imports no embedding/runtime model factory. `independent-predicate-requirements06.json` preserves analyst labels, nested support/contribution groups and all67 source mappings.

This is a conditional source-set availability study on one already exposed question and fixed candidate pool. The analyst's bundle definitions are AI review, not independent human Gold or full-corpus relevance labels. Availability does not prove complete scientific entailment, model use, answer correctness, citation validity of a newly generated answer, learning benefit or native publication. Corpus recall, human retrieval metrics and answer accuracy stay null. No live answer or browser timing was obtained. Stable p95 and causal speed improvement remain unestablished. The results support retaining the evaluated tradeoff and testing source coverage explicitly, not changing the default retrieval policy.
