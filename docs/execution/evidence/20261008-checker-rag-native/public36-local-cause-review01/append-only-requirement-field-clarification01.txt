REQUIREMENT EVIDENCE FIELD SHAPE (structure only): Every requirements[i].evidence[j] object has exactly three keys: evidence_id (a string), fragment_id (one string), and quote (one exact contiguous source substring). A shape-only example is {"evidence_id":"EXAMPLE_EVIDENCE","fragment_id":"EXAMPLE_FRAGMENT","quote":"EXAMPLE_EXACT_SOURCE_SUBSTRING"}; replace all example values using the actual submitted source. Keep claims[i].citations[j].fragment_ids as an array under its unchanged citation schema. These two objects have different key sets; never use fragment_ids in a requirement evidence object. Do not add either field to a variant that excludes it. This layout clarification supplies no evidence, verdict, positive flag, or permission to repair or discard a returned value. Preserve every actual source identity, exact quote, condition and all original checks.
