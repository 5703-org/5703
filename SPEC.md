## States, concurrency and limits

Current interactive commands additionally accept optional `teaching_mode`, `task_id` and `task_action`, with the exact contract in [api_contract.md](docs/foundation/api_contract.md). A same-problem hint task retains its help level and actual disclosures. More hints advance that owned task; explicit full explanation uses the direct flow; a new problem resets teaching mode. A presentation freezes the checked answer/source projection. Delivered events are committed with publication; rendered/citation/full-source events use owner-scoped idempotent receipts and advance the exposure epoch. Concurrent new exposure invalidates a stale cumulative publication check.

Learning memory moves through opt-in extraction, bounded merge/update, revisioned active/expired state and content-erasing deletion. Off/profile-off fences prevent retrieval and extraction, while revocation prevents old jobs publishing stale memory or answers. Memory background jobs share the durable worker infrastructure but have their own two-call/90-second budget. Current requests freeze the checker configuration with output reservation `max(generator.max_tokens,4096)` and complete context-window checks; generator output reservations remain unchanged. The offline judge has a separate two-call/90-second budget and accounting.

Job states: queued → running (or bounded retry_wait) → succeeded/failed/cancelled. Logical answer states: queued → processing → answered/clarification/refused/error/cancelled. Processing states expose registration/parsing/cleaning/validation and ready/quarantined/failed; `ready` means validated chunks, while vector creation belongs to release execution. Releases progress building → validated → active/retired, or failed. Experiments retain draft/frozen/running/completed/cancelled/environment_changed/failed states.

The E5 factory now reuses at most two cached model instances, keyed by the exact model, revision, dimension, device and cache-folder arguments. A lock serializes first construction.
